# Stable v3.0.37 — Classic fixes and CYD-2432S028-L promotion

Jim reported "Ok all tested" and explicitly approved the release and removal of
CYD-2432S028-L's Development-only status. This records owner-reported hardware
acceptance, not new independent telemetry or an enumerated checklist. It does
not establish blanket RF/peripheral qualification or compatibility with all clones.

## Fixes since Stable v3.0.27

- **CYD-2432S028-L:** isolate @gabecamp's PR #25 white-bar alternate display
  mapping and calibration intent as an explicit board profile. JimGat's maintained
  integration preserves the existing generic CYD and HackerBox transforms,
  colors and calibration namespaces. The original contributor reported the
  white-bar fix on HW458 TPM408-2.8; touch was unverified in that historical
  report. Jim's later acceptance and Stable approval supersede that release block.
  PR #25 was integrated with adaptations; the original diff is not remerged.
- **Classic BLE scans (v3.0.36):** a failed PSRAM allocation attempt followed by
  successful internal fallback no longer falsely aborts Scan and Select after its
  first poll. Diagnostic counters remain; start errors, cancellation and safe
  ownership/retry behavior are retained. This is not comprehensive asynchronous
  BLE failure detection or proof of RF reception on every board.
- **Classic USB Debug (v3.0.28–35):** readable compact counters and all actions
  without scrolling, including HackerBox parity. Explicit acknowledged USB log
  transport is bounded and its opt-in persists across reboot. Physically unplug
  GPS before enabling; keep it disconnected while saved ON. Use **Return normal /
  Reboot** successfully before reconnecting GPS. Logs only: no ROM/bootloader/
  panic capture or interactive Classic console, and overload is not lossless.
- **BLE lifecycle (v3.0.30–32):** serialized scan/Chameleon ownership, failed-init
  recovery, startup publication ordering and stage diagnostics. Existing retained
  owner and cleanup protections stay intact. No new hardware capture is claimed.
- **Retained non-Classic v3.0.33 packages:** include v3.0.32 PSRAM IR task-copy
  memory recovery, scan-completion/channel ownership and Scope sweep corrections,
  plus v3.0.33 ESP32-C5 WiFi Scan and Attack's two normal passes with at most one
  adaptive third pass under its existing 45-second ceiling. Earlier BLE startup/
  lifecycle repairs are included for Waveshare ESP32-C5-Touch-LCD-3.5 (WS-C5-35)
  and the other applicable targets. Classic ESP32/S3 keep their original adaptive
  scan policy. These package contents are source/history verified; acceptance is
  the owner's report, not independently enumerated radio/peripheral results.
- **Flasher:** -L is visible at the normal root, with exact per-board Stable and
  Development manifests and selection preserved on channel changes. Stale async
  responses cannot replace the current selection's manifest. Generic CYD and
  HackerBox are never fallback substitutes. Other experimental boards stay gated.

## Flashing and safety

Open https://jimgat.github.io/CYM/?board=cyd-2432s028-l and select **Stable** for
CYD-2432S028-L v3.0.37; Development uses the same exact board identity. Select
generic CYD or HackerBox only for the corresponding hardware/profile. For -L,
`touch_cyd_l` is isolated from `touch_cal` and `touch_hb`; landscape fallback is
90 degrees, but valid saved orientation wins. Existing profiles need no forced
recalibration. The Kconfig prompt's "Development" suffix is a historical build-time
label retained to preserve the accepted binary inputs, not current support status.

Prefer matching-profile **Quick Flash**, matching installed partitions and **Erase
OFF** for application updates. A merged full image flashes at **0x0000** and can
overwrite NVS even without erase-all. Classic segments: bootloader **0x1000**,
partition table **0x8000**, application **0x10000**. Never use another board's
bootloader/table; use the board-specific release names. Previous release basenames
are retained for compatibility. SD 20 MHz, pins, console policy, calibration data
and both menu layouts are unchanged by this promotion.
