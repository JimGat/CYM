# Cheap Yellow Monster v3.0.27 — Audio RTA, QR Decoder & USB UI Control

Stable v3.0.27 promotes the verified Development firmware without rebuilding or changing binary inputs. This is a new release/tag; the earlier v3.0.0 release and its v3.0.7 refresh remain historical downloads.

## Highlights since Stable v3.0.7

- **Audio RTA on Waveshare ESP32-C5-Touch-LCD-3.5 (WS-C5-35):** a live 24-band digital spectrum with RMS/peak, selected-band detail, Fast/Slow averaging, Freeze/Resume, Reset Peaks and adjustable microphone gain. Gain defaults to 24 dB only when no valid value is saved; supported 0–42 dB steps persist in NVS. Opening Gain pauses analysis without stopping acquisition and preserves an existing Freeze selection.
- **Use debug OFF for normal operation.** Jim confirmed that v3.0.27 responds much faster with debug disabled and that the Gain pause works on his WS-C5-35. This is owner-observed responsiveness, not a measured FPS guarantee. Missing debug settings default OFF; a previously saved ON value remains ON after upgrading. Normal boot/error logging is separate from optional diagnostics.
- **WS-C5-35 QR Decoder:** on-demand camera preview, local decoding, inert escaped results, explicit Scan Again and SD JSON records under `/sdcard/lab/QR`. Camera shutdown precedes SD access. URLs are not opened and decoded content is not executed. Physical camera performance remains subject to the board-specific qualification checklist.
- **FSD USB UI control:** co-developer **@birolt29** supplied the USB driver/PC tooling and related Windows/Back-navigation patches. The maintained `tools/fsd.py` supports bounded reviewed menu routes, screenshots, UI inspection and navigation through the primary USB-C console. Manual commands can activate tools; they are not an unattended radio-safe fuzzer. Classic CYD/HackerBox retain console-none and do not expose FSD.
- **Wi-Fi Scan & Attack exit/re-entry:** integrates co-developer **@birolt29**'s exit/rebuild patch, restores screen stop-hook ownership and prevents an aborted scan's late completion from being assigned to a new scan. A new scan can report busy until retired results drain; physical RF/navigation retests remain distinct from host regression coverage.
- **Focused reliability work:** USB console routing/prompt handling, bounded mDNS initialization/unwind and radio ownership, plus PSRAM placement of retained task-only data on applicable boards. The mDNS worker stack/RTOS controls remain internal. More linked headroom is not proof of live mDNS discovery or network timing accuracy.
- **Official cases:** co-developer **@birolt29**'s six-package collection now includes dedicated NM-CYD-C5 and Classic CYD NM-RF-HAT enclosures, original photos, STL/3MF and EN/DE/TR manuals. Original @birolt29 / @alen29 design credits are retained.

## Upgrade and operate

1. Open https://jimgat.github.io/CYM/ in desktop Chrome or Edge. Select the exact board, **Stable**, and confirm **v3.0.27**. Use the primary programming USB-C port; do not use a GPS/JST UART for diagnostics.
2. For a routine update with a matching existing partition layout, use **Quick Flash** (application only) and leave **Erase OFF**. Back up settings/data first. A merged `*-full.bin` is a different operation at `0x0000` and can overwrite the NVS region even with erase-all disabled; use it for a complete installation, not as a settings-preservation guarantee.
3. Use the release's `SHA256SUMS` and `RELEASE-INSTRUCTIONS.txt` for direct downloads. Bootloaders and partition tables are board-specific: do not mix packages.
4. On console-capable boards enter `debug off`, then `debug status`, at 115200 baud. Successful responses: `Debug OFF persisted; applied immediately` and `Debug OFF`. A persistence error is not success. Enable diagnostics only for bounded troubleshooting.
5. WS-C5-35: Modern **Tools & System → Audio RTA / QR Decoder**; Classic **Home → Audio RTA / QR Decoder**. Back returns to the appropriate parent; Home returns to the chosen layout. Lower gain if the input clips.

Debug OFF does not disable every boot message or generic long-render warning. RTA displays **dBFS, not calibrated SPL or hearing-safety measurements**; it does not record/export/stream audio. WS-C5-35 keeps RX-only GPS on GPIO28 at 9600 baud and touch-only five-second Go Dark wake; do not double-press BOOT or repurpose GPIO28. Existing NVS/partition layouts, SD speeds, console policies and experimental-board gates are unchanged.

## Verification and honest limits

The promoted firmware passed all eight target builds and independent package/version checks. The cycle ran 702 unit tests (701 passed, one expected skip) plus 20 additional host runners. Jim confirmed working Gain-modal pause and substantially better perceived RTA responsiveness with debug OFF on WS-C5-35. No FPS, acoustic calibration, all-board peripheral acceptance, extended soak or leak-free lifecycle claim follows from that observation.

Outstanding physical checks include saved gain after reboot, both menus/rotations, repeated settled Back/Home cycles, long-run RTA/camera behavior, Wi-Fi scan abort/re-entry and neighboring radio-tool cleanup, Clock AP/mDNS discovery and actual NTP replies, GPS/RTC, SD, touch and audio. Existing hardware qualifications remain board-specific. This promotion does not claim the separate NM boot or broader Wardrive issues are fixed.
