# v3.0.47 Development — Messenger

New JimGat Messenger implementation, not an imported contribution. Real ESP-NOW
adapter/session core, existing-style Classic/Modern UI and capability selector.
Future protocols remain unimplemented. Session-only credentials, encrypted unicast
plus PSA HMAC, bounded application ACK reliability and B/D owner handoff.

Classic preliminary link now passes after removal of a redundant 1028-byte
static hex copy in saved GATT detail rendering. A bounded view uses the existing
mutable JSON line and restores its byte afterward; 5,505 sanitized parity cases
preserve exact formatting. No additional allocation, stack/display reduction or
capability removal. All nine final-source builds and 36 packages verified; no physical
acceptance or Stable promotion. Original v3.0.46 rollback remains preserved.

Maintained gates: 89 PASS, 369 unittest cases, 57 harness invocations (overlapping counts). Broad suite: 769 PASS plus one private-capture skip. All 40 release standalones passed. Messenger actual-LVGL: 624 checks; mocked worker: 319 checks. Saved GATT renderer: 5,505 sanitized parity/input-restoration cases.

First transport is direct encrypted ESP-NOW, single peer, 160 UTF-8 bytes; application ACK is not a read receipt. Setup/history are session-only. Existing idle WiFi STA is required; conflicting radio owners are refused. Future BLE, LocalSend, LoRa/Reticulum and NM-RF-HAT-only IR remain visibly unimplemented.

SDK retention after first use, callbacks under real concurrency, physical keyboard response and runtime heap/stack minima require target acceptance. No independent security audit is claimed.
