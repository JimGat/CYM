# v3.0.43 Development candidate — Packages G + C

Co-developer @birolt29 supplied the PN532 retained-handle patch and original native
harness. The integration separately corrects partial-cleanup false readiness,
manager/card lifetime and checked shared-pin refusal. Failed release retains
ownership and permits safe explicit retry instead of losing the handle or
reporting ready with a missing device.

Package C now adds runtime four-HAT admission/ownership, sticky cancellation,
checked stop/error/retry and asynchronous replay completion. Design origin:
@birolt29; production synchronization/emitter/UI corrections and tests: JimGat.
Boot allows explicit TX starts. Removing inhibition never restarts an old job.
Wi-Fi/BLE/AP/NVS remain outside this control. A is maintained; B/D/E/F/H remain deferred. No S3 controller selection, PN532 protocol
rewrite, NM card-detection fix, pin/partition/NVS/display policy change or all-RF
silence claim. All nine development profiles use the intended shared v3.0.43
cycle. Host tests/builds are not physical hardware acceptance or Stable promotion.

Package C adds one lazily allocated 4096-byte internal owner stack/TCB and a
small internal control record; copied replay timings and checked RMT symbol
lifetimes are separate. It refuses admission on insufficient internal memory.
See [HAT TX operator checks](../testing/package-c-hat-tx.md) and [PN532 checks and attribution](../testing/package-g-ownership.md). Raw gate,
resource, exact-source and package hashes are in the task handoff; parent performs
independent review and owns publication. Wiki changes are staged proposals only.
