## Integration corrections

Each pending sample checks caller cancellation, armed two-second deadline,
page reconstruction epoch, active screen and display geometry/rotation. A late
final release cannot succeed. Cancellation sends PRESS_LOST (not CLICK), resets
only the owned pointer, and suppresses a colliding finger until its real release.
Nonphysical cancellation permits immediate retry. Installed LVGL's reset lifecycle
is used; UI never waits for drain. Mailbox ownership survives caller timeout.
Normal final-release navigation is valid; completion is input consumption, NOT
proof of widget hit, destination, application outcome or authorization.

Hardware touch precedes injection. Existing dark/dim/lock/settling and exclusive
ownership guards remain; synthetic input updates touch/activity flags. Dropdown
transient overlays remain valid, and normal keyboard editing receives no new
sleep, timer throttle, debounce or cooldown. Idle work is constant-time with no
tree walk. Host software owns run/route consent; firmware adds no new prompts or
consent-policy layer and does not replace genuine physical/UI safety guards.

BT Observer spinner is parented to function_page, explicitly 18x18 at y=32,
survives list cleaning and is removed by the existing stop hook on Back/Home.
This changes normal UI in BOTH Classic and Modern, even with console disabled.
