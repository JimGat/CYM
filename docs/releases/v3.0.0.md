## Off-grid amateur radio Clock — GPS-disciplined NTP and grid square

Developed especially for off-grid ham-radio operation, CYM's Clock can act as an **NTP server** for an isolated radio computer and an **NTP client** when Internet access is available. With a qualified GPS lock, it disciplines UTC from the receiver and displays a locally calculated **six-character Maidenhead grid square**. No Internet connection is needed for GPS-backed time or the grid readout.

- **AP NTP:** create a local protected Wi-Fi network and serve UTC to your radio computer in the field, including FT4/FT8 operating setups.
- **Client NTP:** recover/synchronize UTC from the public NTP pool when connected; qualified GPS takes priority.
- **Display Only:** use the clock offline without initiating Wi-Fi.
- **Source visibility:** inspect GPS lock, source age, holdover, reliability and conservative uncertainty instead of guessing whether time is trustworthy.

**Stratum-1 reference, not a PPS accuracy guarantee:** with qualified GPS lock, NTP replies advertise **stratum 1 / GPS**. This is the protocol's source classification, not measured near-Stratum-1 timing accuracy. CYM currently uses UART NMEA timing, not a PPS input; its conservative GPS allowance is ±500 ms, and accuracy/drift depend on the receiver, board and network. Public-NTP-backed replies use stratum 2; an untrusted clock reports unsynchronized stratum 16. Check the dashboard and verify your client timing before operating time-sensitive modes.

## WS-C5-35 GPS: confirmed lock, different wiring

**WS-C5-35 has a board-specific GPS exception.** Its firmware uses **UART1 RX on GPIO28, with TX disabled**. Connect **GPS TX to GPIO28**, use common **GND**, and select **9600 baud** for the owner-tested module.

Jim confirmed that the board displays **GPS LOCK**, following repeated successful reboots with the GPS connected. This is hardware evidence on the tested SKU 35419 assembly, not merely a successful build.

On that assembly, the GPIO11/12 UART-labelled J3 routes are not connected. Do not assume the printed UART labels or another board's wiring apply. GPIO28 is also a physical BOOT strap, so runtime BOOT-button polling is disabled on this board; avoid pressing BOOT against an active GPS transmitter. Other boards retain their GPS and BOOT mappings.

[Read the WS-C5-35 wiring and support notes](https://github.com/JimGat/CYM/blob/main/docs/hardware/waveshare-c5-touch-lcd-35.md)

## More capable tools and clearer feedback

- **Chameleon Ultra/Lite RFID workflows:** Saved Cards, key-dictionary status, detection-record export, animation/sleep settings, and improved card-geometry and file-integrity checks. Nonce analysis is an authorized offline workflow, not on-device cracking; physical qualification of the expanded workflows remains ongoing.
- **GATT23 integrations:** optional SD-card metadata for supported external peripherals, with bounded input handling, clearer connection feedback and lifecycle checks.
- **GPS and timekeeping:** board-specific receive handling, improved monitor/baud feedback, and the existing Universal Clock's GPS/NTP/RTC source handling on capable hardware. WS-C5-35 RTC synchronization and reboot holdover have been owner-tested.
- **Everyday usability:** more reliable taps in changing Hidden Camera lists, board-gated battery telemetry with voltage-estimated percentages, and focused navigation and responsiveness corrections across Classic and Modern layouts.
- **Reliability:** tighter BLE lifecycle/error handling, clearer passive-detection failure/warm-up states, and board-aware memory and stack handling, including no-PSRAM targets. Detection results are indicators, not proof that a device is malicious.

## Installing or upgrading

Use the [CYM Web Flasher](https://jimgat.github.io/CYM/) and select your exact board and the Stable channel for the current v3.0.2 firmware refresh of this v3.0.0 release. Experimental boards remain in Development.

Back up important SD-card files and note your settings before flashing. Do not erase the whole device unless you intend to reset it. A full combined image can overwrite settings regions even when erase-all is disabled; follow the board-specific update instructions for a settings-preserving application-only update where appropriate. Images and flash offsets are not interchangeable between board types.

Automated build and package checks do not establish physical qualification of every feature or peripheral. See the board notes for tested behavior and remaining limits.
