implementation handoff's final-verification.json; no Stable/publication action is

## Operator checklist (hardware still pending; do not run automatically)

Use the exact approved board profile/package. Preserve settings and established
GPS/USB-console safety; never use another board's full image. Perform checks in
both Classic and Modern Home layouts, with Back and Home exits.

1. Open RF HAT -> RF433 -> OOK Scan with a known authorized EV1527 source.
   Expected: a 20-bit address/four-bit data row; repeated frames update that row.
   Silence/noise alone must not establish successful reception or broad support.
2. Press Back/Home rapidly and reenter 20 times. Expected: only one live session,
   no stale rows/callback to a destroyed page, no reset. A still-stopping owner
   should report busy/unavailable, retain its resources, then allow a later retry.
3. Switch from nRF24 scan/sniffer/jammer/Futaba, RF433 capture/jammer and IR
   capture/jammer to OOK Scan/Fox Hunt. Never transmit outside an authorized bench.
   Expected: prior worker completion before new pin use; refusal if it cannot join.
   CC1101 or RFID active ownership must refuse rather than force-delete a worker.
4. Open RF433 Fox Hunt. Expected: activity-only message and edges/s, not true RSSI.
   Exit and reenter; ensure no stuck activity handler or changed vibration setting.
5. IR capture: successful capture -> successful capture; silent timeout -> known
   remote capture; repeat around timeout and Back/reentry. Expected: no stale
   prior frame and no stuck RUN-state failure; replay a previously accepted signal
   only on the authorized bench and verify the target responds independently.
6. CC1101 Alarm Sensors: verify the same known EV1527 message. A weather result
   is not acceptance of this decoder. Verify display/touch/SD and other pin users
   still work on the exact hardware after switching.

Record board, package SHA-256, layout, steps, observed screen/serial evidence,
expected/actual result and source device. Build success alone cannot close this list.
