# v3.0.28 Development — Classic USB Debug

Stable remains v3.0.27. This is a Development update, not hardware acceptance or a Stable release.

Classic CYD-2432S028 and HackerBox Amberjack 0131 CYD gain a separate Classic USB Debug option under Settings > Hardware Options in both Home layouts. Physically disconnect GPS and any other driver on GPIO1 before acknowledging enable. GPS initialization, polling, detection and control access are inhibited before UART0 logging begins. Software cannot electrically isolate a powered GPS transmitter.

Normal boot retains console NONE, silent application/bootloader UART logging and existing GPS behavior. The new transport defaults OFF each boot and is never persisted. Existing Debug diagnostics verbosity remains separate. Logs use the USB-to-UART bridge at 115200 8N1, without a command prompt. Bounded nonblocking output may truncate/drop bursts; startup replay, ROM, panic and backtrace capture are not promised. Return normal / Reboot releases the transport before reboot. Keep GPS disconnected and power off before reconnecting it. Failed transitions keep GPS inhibited.

## Retest scope

Physical confirmation remains required on Classic and HackerBox: normal GPS before/after debug, GPIO1 TX ownership, serial output, cancellation, repeated enable/reboot, both Home layouts/orientations, and RF-HAT/SD/radio coexistence. Other profiles retain their existing console and GPS configuration; compilation is not peripheral or timing qualification. No GPS pin reassignment, NVS erasure, partition change or SD-speed change.
