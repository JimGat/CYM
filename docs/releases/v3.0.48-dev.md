# v3.0.48 Development - Chat menu polish

Classic Home > Chat and Modern Tools/System > Chat now use a dedicated
Font Awesome speech-bubble icon. The screen title is Chat. This is visible UI
polish only: internal Messenger dispatch, messaging protocols, encryption,
settings, keyboard, timers and lifecycle remain unchanged.

The existing pinned Font Awesome Free 6.7.2 solid font supplies U+F075
(comment) at 20px/4bpp. All 93 prior glyph pixels and metrics are preserved.
Existing board support labels and hardware-qualification limits are unchanged.
Host rendering and cross-board builds are not physical display/touch acceptance.
