# CYD-2432S028-L — Development alternate mapping

CYD-2432S028-L is an explicit alternate mapping selection, not a replacement for
CYD-2432S028 or HackerBox CYD. It does not identify a different controller or
prove a mounting difference. Existing generic and HackerBox mappings, orientation
fallbacks, colors and stored calibration remain unchanged; existing profiles do
not acquire forced recalibration. Landscape users do not all need the -L profile.

## Select and build

Use Development and the exact CYD-2432S028-L board. The opt-in flasher URL is https://jimgat.github.io/CYM/beta/?board=cyd-2432s028-l .
There is no Stable artifact: toggling to Stable preserves this board selection,
reports unavailable and offers no substitute generic/HackerBox download.
Do not flash another profile to work around an unavailable channel.

From the repository root after sourcing ESP-IDF v6.0.2:

    make cyd-2432s028-l

Expected package: ESP32/binaries-cyd-2432s028-l/CYM-CYD-2432S028-L-full.bin .
The merged full image starts at 0x0000; its bootloader is at 0x1000, partition
table at 0x8000 and application at 0x10000. Full-image flashing can overwrite
NVS even without erase-all; application-only updates preserve NVS only with a
matching existing partition layout. Never erase settings to force the default.

## Expected behavior and physical acceptance still required

Native 240x320, ILI9341 path, RGB order, inversion off, swap_xy(false),
mirror(true,false). LVGL supplies rotation; fallback orientation is 1 (90-degree
landscape), but any valid saved orientation 0..3 wins. Fresh touch_cyd_l storage
uses the existing HackerBox corner-axis-detect solver, not copied calibration.
First missing calibration enters the native-portrait calibration path without
requiring calibrated navigation; timeout and success restore selected orientation.
Generic touch_cal and HackerBox touch_hb remain untouched.

On the exact candidate, ask the tester to perform:

1. Cold power-off/boot: all four native borders/corners, readable non-mirrored
   text, accepted colors and no white strip. Record the literal board markings.
2. Fresh -L calibration: all targets visible, corner and center alignment,
   confirmation retry, timeout restore, keyboard taps and reboot persistence.
3. All four orientations (both landscapes), saved-setting precedence, Classic
   and Modern navigation, Settings/Screen and Back/Home.
4. Compact USB Debug popup: all actions visible without scrolling. Physically
   disconnect GPS before acknowledged enable; keep disconnected across reboot
   while transport is saved ON. Return normal and reboot before reconnecting.
5. BLE scan/reentry under real landscape UI/allocation pressure, Debug ON/OFF,
   SD/RF-HAT/GPS coexistence and internal heap/largest-block measurements.

Software contracts/builds do not qualify physical calibration, rendering,
all-orientation input, peripheral behavior or BLE memory-pressure acceptance.
No UART rerouting, unsolicited logging, task-stack/buffer, SD 20MHz, pin or
partition changes are part of this profile. The v3.0.36 allocation-attempt versus
terminal BLE failure fix and v3.0.35 compact acknowledged-debug UI are retained.

The shared ESP32 no-PSRAM version selector advances generic CYD, HackerBox and
-L to v3.0.37. Existing non-Classic package/manifest bytes and source versions
are preserved despite compatibility builds. No Stable publication is authorized.
