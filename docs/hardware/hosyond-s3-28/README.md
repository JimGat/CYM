# Hosyond/LCDWiki ESP32-S3 2.8-inch source documents

Board: ES3C28P capacitive-touch model (ES3N28P is the no-touch sibling).

Official source: https://www.lcdwiki.com/2.8inch_ESP32-S3_Display

Included here:

- product specification
- hardware schematic
- ESP32-S3 IO allocation workbook
- ILI9341V initialization table and controller datasheet
- FT6336G touch-controller datasheet

The official page identifies an ESP32-S3 N16R8, ILI9341V 240×320 4-line SPI panel, and FT6336G I2C capacitive touch. This documentation supports port planning; it does not mean CYM hardware support is complete.
