# Hosyond/LCDWiki ESP32-S3 4.0-inch source documents

Board: ES3C40P capacitive-touch model.

Official source: https://www.lcdwiki.com/4.0inch_ESP32-S3_Display

Included here:

- product specification
- hardware schematic
- ST7796 initialization table and controller datasheet
- FT6336U touch-controller datasheet

The official page identifies an ESP32-S3 N16R8, ST7796S 320×480 4-line SPI panel, and FT6336U I2C capacitive touch. LCDWiki currently links the 4.0-inch page's IO-workbook entry to the 2.8-inch ES3C28P workbook, so that workbook is deliberately not duplicated here as 4.0-inch evidence. Use the 4.0-inch schematic and pin table until an independent workbook is published.

This documentation supports port planning; it does not mean CYM hardware support is complete.
