# CYM Cases

## Official Cases — start here

The **Official CYM Cases** are the collection supplied by CYM co-developer [@birolt29](https://github.com/birolt29). The original manuals credit **@birolt29 and @alen29**; the Thingiverse package README/license files identify the uploader as `alen29`. Both original credits are preserved without assuming the relationship between the handles.

[Official case collection, multilingual manuals, models and photos](birolt29/README.md).

- NM-CYD-C5
- Classic CYD / 2432S028R
- Waveshare WS-C5-28
- Hosyond ES3C35P 3.5-inch — Standard and Slim

The supplied case packages use **CC BY-NC-ND 4.0**, independently of the CYM firmware license. Preserve attribution and share the supplied files unmodified. Commercial use or distributing modified designs requires permission from the rights holders. [License terms](https://creativecommons.org/licenses/by-nc-nd/4.0/).

See the collection’s assembly caveats before wiring GPS or charging hardware. Official-case status does not qualify peripheral wiring or RF-HAT fit.

## Alternative community / RF-HAT cases

The older designs remain available as alternatives, particularly for builds needing a full RF-HAT stack:

- [MakerWorld — NM-RF-HAT / CYD2USB / ATGM336H / 18650](https://makerworld.com/en/models/2670158-case-for-nm-rf-hat-cyd2usb-atgm336h-18650)
- [Printables — magnetic NM-RF-HAT enclosure](https://www.printables.com/model/1638712-cyd-nm-rf-hat-enclosure-case-magnetic-6x2mm-magnet)
- [Thingiverse — CYM-NM28C5 enclosure](https://www.thingiverse.com/thing:7305463)

Check each designer’s own license, exact board/stack fit and DIP-switch access. These are alternatives, not the Official CYM Case collection.
